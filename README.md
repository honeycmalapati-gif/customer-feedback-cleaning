# Customer Feedback Data Cleaning

A small Python project that cleans messy customer review data from a JSON file.

## What it does
- Loads raw review data from `store_data.json`
- Converts text ratings ("four", "two") to numbers
- Handles missing age values
- Removes duplicate users

## Tools
Python, JSON

## How to run
Open `thinking_data.ipynb` in Jupyter and run all cells.
